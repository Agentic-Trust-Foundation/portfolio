# Agentic Trust Foundation — Engineering Portfolio

Evidence-driven portfolio for the Agentic Trust Foundation and Agent-Pay ecosystem.

## Stack
- Next.js App Router
- TypeScript
- Static-first presentation
- Responsive CSS
- Vercel-ready

## Routes
- / — overview and engineering journey
- /architecture — trust/delegation/payment architecture
- /phases — V1→V2 finalization timeline
- /protocols — protocol gap-analysis dimensions
- /verification — evidence chain and boundaries
- /repositories — repository map and exact current baselines
- /post-v2 — ecosystem enablement, independent adoption, production evidence

## Evidence rule
This site intentionally distinguishes CI success from production evidence, Foundation-owned integration from independent adoption, and existing verification tooling from independent certification.

Current repository state was audited against GitHub on 2026-09-24. Current main-branch state is authoritative where it differs from historical baseline notes.

## Deployment
Designed for zero-backend deployment on Vercel. Connect this repository and use the repository root as the project root.
